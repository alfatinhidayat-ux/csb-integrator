### Terkait erat, kemungkinan dipakai juga di layar dashboard (modul `saldo_kas`)
Ini bukan di bawah path `laporan/dashboard/` tapi controller-nya dipanggil oleh `FetchSaldoKasHariIniController`/`Service` — kemungkinan endpoint-nya ada di modul `saldo_kas` terpisah (nama path pastinya tidak muncul sebagai string statis, mungkin dibentuk dinamis dari base + nama resource). Kandidat nama endpoint berdasarkan nama file:
- `fetch_kas_harian_rekap`
- `fetch_kas_penjualan_terakhir`
- `fetch_kas_sistem_terakhir`
- `fetch_saldo_kas_by_tanggal`

Ini perlu dikonfirmasi lewat intercept traffic karena nama path-nya tidak eksplisit tertulis sebagai string (kemungkinan dibangun dari konstanta lain).

**Catatan penting:**
- Semua endpoint di atas **tidak** pakai prefix `/api/` — path-nya langsung digabung ke base URL.
- Tidak ditemukan versi API (`v1`, `v2`) di path.
- Sangat kemungkinan pakai auth Bearer token (umum di Flutter+Dio), tapi header/format auth-nya tidak terlihat sebagai string statis — perlu dikonfirmasi lewat intercept.
